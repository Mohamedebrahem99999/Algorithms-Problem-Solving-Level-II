# Problem: Digit Frequency in a Number

Write a program to read a main number and a specific digit, then count and print how many times that digit appears inside the main number.

---

## Input

```text
122324
2
```

_(Main Number: 122324, Digit to Search: 2)_

## Output

**Plaintext**

```
Enter a number:
122324
Enter a positive number to get frequency:
2
The Frequency of 2 = 3
```
