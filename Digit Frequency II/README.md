# Problem: Print All Digits Frequency (Ordered)

Write a program to read a main number, then calculate and print the frequency of each digit (from 0 to 9) present in that number.

---

## Input

```text
Enter a number:
10204
```

Output

```
The Frequency of the 0 is 2
The Frequency of the 1 is 1
The Frequency of the 2 is 1
The Frequency of the 4 is 1
```
