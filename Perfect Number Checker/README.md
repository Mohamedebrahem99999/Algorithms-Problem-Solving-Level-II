# Perfect Number Checker

## Problem Statement

Write a program that prompts the user to enter a positive number, then determines whether that number is a **Perfect Number**.

### Definition

A **perfect number** is a positive integer that is equal to the sum of its proper divisors (all divisors of the number excluding the number itself).

### Requirements

- Keep prompting the user until a **positive number** is entered.
- Check whether the number is perfect.
- Print a message stating whether the number is or is not perfect.

### Example

**Input:**

```
Please enter a positive number?
28
```

**Output:**

```
28 Is Perfect Number.
```

**Input:**

```
Please enter a positive number?
15
```

**Output:**

```
15 Is NOT Perfect Number.
```
