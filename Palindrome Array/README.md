# Problem: Check Palindrome Array

Write a program to fill an array with numbers, then check if it is a Palindrome array or not.

> **Note:** A Palindrome array can be read the same from right to left as from left to right.

---

## Input

```
10 20 30 30 20 10
```

### Output

```Plaintext
Array Elements:
10 20 30 30 20 10
Yes array is Palindrome
```
