# Problem: Fill Array with Keys

Write a program to generate a specified number of random serial keys (each composed of custom syllables and lengths), store them inside a string array, and then print all array elements.

---

## Input

```text
5
4
4
(Number of Keys / Array Length: 5, Syllables per Key: 4, Syllable Length: 4)
```

## Output

```Plaintext
Enter the number of keys: 5
Enter the number of Syllables: 4
Enter the length of each syllable: 4

Array elements:

Array[0] : ETAI-HJUV-PEIP-CFRX
Array[1] : UMCO-YSPQ-PHYK-STIL
Array[2] : QBSR-MZEC-BYNA-DSYK
Array[3] : MISQ-ULYB-ZRAZ-LMAG
Array[4] : NQCR-PPFJ-KZLF-ZHMT
```
