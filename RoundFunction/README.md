
# Problem: Round Numbers (My Round)

Write a program to print round of numbers , don't use built in round function.

---

### Example 1

**Input:**

```text
10.7
```

**Output:**

```Plaintext
My Round Result : 11
C++ Round Result: 11
```

### Example 2

**Input:**

```Plaintext
10.3
```

**Output:**

```Plaintext
My Round Result : 10
C++ Round Result: 10
```

### Example 3

**Input:**

```Plaintext
-10.7
```

**Output:**

```Plaintext
My Round Result : -11
C++ Round Result: -11
```
