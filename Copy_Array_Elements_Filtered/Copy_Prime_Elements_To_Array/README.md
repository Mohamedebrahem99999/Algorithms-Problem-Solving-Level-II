# Copy Prime Numbers to Array

Write a program to fill an array (max size 100) with random numbers from 1 to 100, copy only the prime numbers to another array using `Append` / `AddArrayElement`, and print the resulting array.

---

## Input

```text
10
```

## Output

```Plaintext
Enter the size of the Array: 10
Enter the Length of the Array: 10
Array 1 elements:
61 100 32 75 81 95 50 98 13 70

Array 2 Prime numbers:
61 13
```
