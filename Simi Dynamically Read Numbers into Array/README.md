
# Problem: Add Array Elements Dynamically

Write a program to dynamically read numbers from the user and save them into an array (max size 100), allocating a semi-dynamic array length based on user input.

---

## Input

```text
10
1
20
1
30
0
```


## Output

```Plaintext
Please enter a number? 10
Do you want to add more numbers? [0]:No, [1]:yes? 1
Please enter a number? 20
Do you want to add more numbers? [0]:No, [1]:yes? 1
Please enter a number? 30
Do you want to add more numbers? [0]:No, [1]:yes? 0

Array Length: 3
Array elements: 10 20 30
```
