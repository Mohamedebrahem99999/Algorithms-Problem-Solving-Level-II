# Problem: Letter Pattern

Write a program to read a positive number $N$, then print a letter pattern where each row prints the $i$-th letter of the alphabet (starting from 'A' for 1) repeated $i$ times, up to the $N$-th letter.

---

## Input

```
5
```

### Output

```Plaintext
Enter a positive number: 5
A
BB
CCC
DDDD
EEEEE
```
