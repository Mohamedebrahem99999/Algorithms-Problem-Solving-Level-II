# Problem: Print Perfect Numbers From 1 to N

Write a program to read a positive number $N$, then print all Perfect Numbers from $1$ to $N$.

> **Note:** A **Perfect Number** is a number that is equal to the sum of its proper divisors (excluding the number itself).
> *Example:* $6 = 1 + 2 + 3$.

---

### Example

**Input:**

```
50
```

**Output:**

```Plaintext
6
28
```
