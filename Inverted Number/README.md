# Inverted Number Pattern Problem

## Problem Statement

Write a program to read a number and print an inverted pattern as follows:

---

### Example 1

**Input:**

```text
3
```

**Output:**

```text
333
22
1
```

---

### Example 2

**Input:**

```text
5
```

**Output:**

```text
55555
4444
333
22
1
```
