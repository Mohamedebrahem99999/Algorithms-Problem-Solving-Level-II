
# Problem: Inverted Letter Pattern

Write a program to read a positive number $N$, then print an inverted letter pattern where the $i$-th letter of the alphabet (starting from 'A' for 1) is repeated $i$ times on its respective row, decreasing down to 'A'.

---

## Input

```text
5
```

## Output

```Enter
EEEEE
DDDD
CCC
BB
A
```
