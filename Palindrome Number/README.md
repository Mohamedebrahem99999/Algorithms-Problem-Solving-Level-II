
# Problem: Check Palindrome Number

Write a program to read a number from the user, then check whether it is a **Palindrome** number or not.

> **Note:** A Palindrome number is a number that remains the same when its digits are reversed (e.g., `12321`, `121`).

---

### Example 1

**Input:**

```text
12321
```

**Output**

```
Palindrome
```

### Example 2

**Input**

```Plaintext
12345
```

**Output**

```Plaintext
Not Palindrome
```
