
# Problem: Reverse Array Elements

Write a program to initialize an array, fill it with random numbers, and reverse its elements in place.

---

### Example

**Input:**

```text
Enter the size of the array: 5
Enter array length: 5
```

**Output:**

```Plaintext
Array Before Reversing:
42 12 89 5 33
Array After Reversing:
33 5 89 12 42
```
