## Problem: Insert Element in Array & Get Frequency

### Description

Write a program that:

1. Fill an array with elements entered manually by the user.
2. Asks the user to enter a number, then prints how many times that number appears (its **frequency**) in the array.

### Input

- The array elements.
- A number to search for its frequency in the array.

### Output

- The frequency of the given number in the array.

### Example

```
Enter the size of the array: 10
Enter the length of the array: 5
Enter Element 1: 3
Enter Element 2: 7
Enter Element 3: 3
Enter Element 4: 9
Enter Element 5: 3

Array elements
3  7  3  9  3

Enter a number To get Frequency in the array: 3
3
```
