# Problem: Dynamic Key Generator

Write a program to generate a specified number of random keys, where each key consists of a custom number of syllables and characters per syllable.

---

Input

```text
5
4
4
```

(Number of keys: 5, Syllables per key: 4, Length of each syllable: 4)

Output

```
Key [1]: ETAI-HJUV-PEIP-CFRX
Key [2]: UMCO-YSPQ-PHYK-STIL
Key [3]: QBSR-MZEC-BYNA-DSYK
Key [4]: MISQ-ULYB-ZRAZ-LMAG
Key [5]: NQCR-PPFJ-KZLF-ZHMT
```
