# Problem: Fill Array & Search for a Number

Write a program to fill an array with max size **100** with random numbers from **1 to 100**, read a number, and print if it's found or not (reuse code from the previous problem).

---

## Example 1

**Input:**

```
10
```

**Output:**

```
Please enter a number to search for?
66

Number you are looking for is: 66
Yes, The number is found :-)
```

---

## Example 2

**Input:**

```
10
```

**Output:**

```
Please enter a number to search for?
19

Number you are looking for is: 19
No, The number is not found :-(
```
